# A Little World · 盐的房间

一个用 Three.js 做的等距 3D 小房间，纯静态网页：没有服务器、没有框架、不需要域名。

房间里有沙发、书柜、书桌、电脑、唱片机、磁带、吉他、鼓、自行车，还有地图、鸟图鉴和电影纸箱。点房间里的东西会放大、弹气泡；部分东西可以听声音、写文字、换照片。

## 本地预览

**Windows**：双击 `预览房间.cmd`，浏览器会自动打开 `http://127.0.0.1:5173/`。

**Mac / 其他**：在这个文件夹里打开终端，执行：

```bash
node server.mjs
```

然后打开 `http://127.0.0.1:5173/`。

> 不要直接双击 `index.html`。浏览器不允许 `file://` 下加载 3D 模型和 ES 模块，会白屏。

进门密码是 `041111`，在 `js/content.js` 里可以改。

## 想改内容

- **所有文字**：`js/content.js`（每段都有中文注释）
- **歌单**：`js/playlist.js`
- **照片**：`assets/birds/`、`assets/camera/`、`assets/movies/`
- **明信片和画**：`js/art.js`

## 上线到 GitHub Pages

见同目录的 `如何上线到GitHub.md`，一步一步照着做即可。

## 说明

- 磁带、地图故事、电影观后感、书单、相册上传等，保存在**浏览器本地**，换设备或清缓存会丢；这是纯静态网页的限制。
- 阅读界面会尝试内嵌网页 / PDF，部分网站禁止内嵌时会提示「在新标签打开」。
- 整个文件夹约 54MB，主要是音频（约 22MB）和 3D 模型。
